# BE-D01 · Независимая проверка полного прогона

[Фактический отчёт](../reports/20261112T035051Z-72099.md). Чистый проект `srastemsya-be-d01-final-tester` использовал Nginx на порту 18084. Пустой набор проверен отдельно через шлюз на порту 18082. Все 10 проверок прошли.

- Проверены стабильная карусель без геолокации, выборка по фильтрам первой подборки, три пустых массива на пустом стенде, единые карточки и детали, категории, включительные границы карты, три типа объектов и невидимость черновика.
- Поиск и карта выдали по 20 результатов на первой странице. Переходы по страницам не повторили объекты. Повтор курсора сохранил состав страницы, чужой аккаунт и изменённый фильтр не получили её. Истечение курсоров проверено [отдельным прогоном](20261112T042628Z-73701.md).
- Граничные и неполные параметры карты вернули `422 VALIDATION_ERROR`. Семь защищённых маршрутов вернули `401 UNAUTHENTICATED` без токена и `403 PROFILE_INCOMPLETE` с незавершённым профилем. Завершение регистрации открыло каталог и комнаты с той же сессией.
- Поля мастер-класса и права соответствовали ролям организатора, участника и посетителя в обоих маршрутах чтения. Подтверждённая запись учтена в остатке мест. Команды изменения записей и публикации входят в BE-D02.
- Повторная команда Compose сохранила видимые данные без дублей. Только Nginx опубликовал порт. При остановленной БД catalog вернул 503, остальные проверки готовности сохранили 200, после запуска БД catalog вернул 200. Пароль не обнаружен в проверенных журналах, имя пользователя и пароль не обнаружены в HTTP-ответе и журнале catalog.

В [первом прогоне](../reports/20261112T034711Z-71563.md) предварительный тест включал `GET /v1/events` из BE-D02, где наблюдался 404. Для BE-D01 проверены детали `GET /v1/events/{id}`. Во [втором прогоне](../reports/20261112T034828Z-71707.md) сравнение включало непрозрачный курсор нового запроса. Исправленный тест сравнивает данные каталога. [Следующий прогон](../reports/20261112T034916Z-71891.md) пришёлся на 60-секундное ограничение повторной авторизации. [Повтор](../reports/20261112T034937Z-71958.md) после этого интервала прошёл. Полный прогон использовал новый проект, включая профиль в исходном состоянии.
