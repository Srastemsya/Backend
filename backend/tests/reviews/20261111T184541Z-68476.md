# Ревью challenge и сессии

- AC-02 прошёл. Неверный код дал `422 OTP_INVALID`, ранняя отправка дала `429 RATE_LIMITED` с Retry-After, заменённый challenge дал `410 OTP_EXPIRED`. Два параллельных verify с разными ключами дали 200 и 410. Повтор с ключом победителя вернул исходную сессию.
- AC-03 прошёл. Access JWT содержал обязательные claims и срок 900 секунд. Refresh с тем же ключом вернул ту же пару, использование старого refresh с новым ключом отозвало семейство. Каталог и комнаты отклонили JWT с изменённой подписью, JWT отозванного семейства и JWT после logout. Refresh также отклонялся после обоих способов отзыва.
