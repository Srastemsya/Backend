# Ревью готовности и отказа Redis

- AC-06 прошёл. Каждый readiness-маршрут Nginx возвращал 503 с причиной db во время остановки собственной базы и 200 после запуска. Другие базы оставались доступны. Профиль сохранился. При остановке Redis оба защищённых маршрута отказали в доступе с действующим JWT. После восстановления Redis проверки готовности вернули 200.
- PM подтвердил очищенные результаты проверки логов при остановке и восстановлении БД. В логах приложений, proxy, баз и Redis отсутствовали DSN, известный пароль, Bearer-заголовок и маркер синтетического контакта.
- PM также подтвердил доказательства TTL и ACL Redis, защиты проверочных значений и повторных ответов, выделенного PostgreSQL, доступа к закрытому JWT-ключу только из identity и конфигурации восстановления и Nginx.
