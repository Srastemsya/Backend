# Developer review BE-D02

The suite verifies the shared catalog projection and BE-D01 fixtures in the catalog runtime, injects a failure after the outbox write to verify PostgreSQL rollback, and consumes an actual Kafka record while observing invalidation of its prior Redis revision. It requires a dedicated development Compose stack and creates synthetic events. The earlier Kafka test invocation failed because its consumer lacked context manager support. The final suite closes the consumer explicitly. HTTP boundaries, concurrency, dependency interruption and restart are independently verified by Tester.
