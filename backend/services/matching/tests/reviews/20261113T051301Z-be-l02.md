# BE-L02 · Оценка результатов

- Первый прогон подтвердил одинаковые пулы и составы, нумерацию 1 → 2 → 3, исчерпание 22 карточек и страницы одиночной выдачи 20 + 2. Для D03-03 и D03-10 посторонний — person5, который не состоял в проверяемых комнатах.
- В первом прогоне были два сбоя тестовых предпосылок. Вместо произвольного адреса, отклонённого в dev, повторный INT-01 использовал `new@example.test` из пакета Tester. В D03-10 ожидание заменено на `SESSION_EXPIRED` согласно Discovery v1, который стенд и вернул. Оба повтора прошли. В повторе также проверены категории всех 35 смешанных карточек.
- INT-02 воспроизвёл 503 и восстановление 200 через Nginx для каждой из трёх собственных БД. Ответы проверены на строки подключения и поля пароля, журналы сервисов за последнюю минуту — на PostgreSQL URI со встроенными учётными данными. Полные журналы в отчёт не включены.
- Сценарий AC-06 подтвердил неизменный срок комнаты во втором раунде, отсутствие результата при двух из четырёх лайков, матч при трёх из четырёх, единый результат параллельных завершений, идемпотентный повтор и сохранение результата после перезапуска. Для long poll сравнены версии записи, ответа и повторного чтения. Границу фиксации в PostgreSQL чёрный ящик проверяет по видимости результата через HTTP.
- В AC-05 проверены существование локальных целей ссылок и заголовков, а также согласованность изменений про размер пула и нумерацию. Внешние ссылки, не относящиеся к изменению, не проверялись.
