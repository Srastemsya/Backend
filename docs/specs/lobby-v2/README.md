# Бэкенд комнаты v2 · весовой выбор в лобби

[Контракт комнаты v2](../../contracts/lobby-v2.md) · [Разработка](implementation.md) · [Приёмка](acceptance.md) · [Памятка разработчика](developer-guide.md) · [Первый релиз](../discovery-v1/README.md)

Доработка сервиса swipes поверх принятого BE-D03. Группа получает пулы по 10 карточек, матч требует 70% лайков, следующий пул учитывает прошлые голоса, а при исчерпании карточек побеждает лидер по баллам.

Работа разбита на семь маленьких пакетов. Каждый пакет меняет одно правило, имеет пошаговый план и собственную приёмку.

| Пакет | Результат | Зависимости | Ветка и база PR |
|---|---|---|---|
| [BE-L01](implementation.md#be-l01--стендовые-данные) | Десять dev-участников и три набора карточек для проверки комнат. Логика не меняется | BE-D03 | `be-l01` от `dev` |
| [BE-L02](implementation.md#be-l02--пул-из-10-и-номер-раунда) | Пул раунда до 10 карточек, поле `number` | BE-L01 | `be-l02` от `be-l01` |
| [BE-L03](implementation.md#be-l03--порог-70-и-поля-результата) | Матч при 70% лайков, поля `basis`, `likes`, `memberCount` в результате | BE-L02 | `be-l03` от `be-l02` |
| [BE-L04](implementation.md#be-l04--срок-на-каждый-раунд) | 30 минут на каждый раунд, поле `expiresAt` | BE-L03 | `be-l04` от `be-l03` |
| [BE-L05](implementation.md#be-l05--следующий-пул-по-весам-категорий) | Следующий пул сортируется по весам категорий | BE-L04 | `be-l05` от `be-l04` |
| [BE-L06](implementation.md#be-l06--итог-по-баллам-при-исчерпании) | Победитель по баллам, когда карточки закончились | BE-L05 | `be-l06` от `be-l05` |
| [BE-L07](implementation.md#be-l07--сверка-документов-и-сквозной-прогон) | Документы без противоречий, сквозной прогон релиза | BE-L06 | `be-l07` от `be-l06` |

Пакеты меняют один сервис и выполняются строго по порядку стопкой веток. База PR следующего пакета — ветка предыдущего до его слияния в `dev`.

Изменения касаются только комнат. Одиночная выдача, приглашения, long polling, каталог и identity сохраняют поведение Discovery v1. Экран ленты в [описании дизайна](../../design/feed.md) пока описывает большинство «больше половины» и обновляется отдельной дизайн-задачей.
