# Приёмка BE-L06

Источник требований: [L06-01 … L06-06](../../../docs/specs/lobby-v2/acceptance.md#be-l06--итог-по-баллам-при-исчерпании), [контракт](../../../docs/contracts/lobby-v2.md#карточки-закончились) и [шаги пакета](../../../docs/specs/lobby-v2/implementation.md#be-l06--итог-по-баллам-при-исчерпании).

| ID | Действие | Ожидаемый результат |
|---|---|---|
| AC-01 (L06-01) | На наборе `dev-lobby-two` пройти оба раунда без порога, оставив единственного лидера в первом раунде | `MATCHED`, `round=null`, `result.basis="TOP_SCORE"`, победитель — карточка с максимумом лайков за все раунды. `likes` и `memberCount` соответствуют голосам и составу. |
| AC-02 (L06-02) | Дать равный максимум карточкам разных раундов, затем в новой комнате двум карточкам одного раунда | Побеждает карточка более раннего раунда. Внутри раунда — более ранняя в пуле. |
| AC-03 (L06-03) | На наборе `dev-lobby-short` пропустить все карточки всеми участниками | `EXHAUSTED`, `round=null`, `result=null`. |
| AC-04 (L06-04) | Получить матч по порогу в первом раунде. Запустить комнату с фильтрами без кандидатов | Матч: `result.basis="THRESHOLD"`. Пустой старт: `EXHAUSTED`, `round=null`, `result=null`. |
| AC-05 (L06-05) | Последние два участника завершают последний раунд параллельно. Повторить завершение, проголосовать в старый раунд, держать long poll организатора | Все видят один результат. Повтор возвращает текущий snapshot, голос даёт `409 STALE_ROUND`. Long poll доставляет итоговую версию. Чужих голосов в ответах нет. |
| AC-06 (L06-06) | Повторить L05-01 … L05-06 | Критерии выполняются. |

Проверки Developer: модульные тесты выбора лидера, применимые архитектурные проверки и обновлённая документация swipes, Discovery v1, BE-04 и мобильного контракта.
